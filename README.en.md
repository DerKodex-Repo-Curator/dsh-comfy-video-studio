# dsh-comfy-video-studio

[中文](./README.md) | English

A full-screen ComfyUI MiniMax H3 video studio for DeepSeek Harness. Version 0.6 adds server-managed ComfyUI connection presets with runtime switching, task-level connection snapshots, optional explicit self-signed TLS support, and direct submission of the bundled API workflow JSON to the selected instance. It also provides text-to-video, image-to-video, and one-to-three arbitrary-time keyframe workflows; persistent generation history; prompt optimization; image upload; live progress; Range-enabled playback; and absolute-directory delivery on the Harness host.

See [README.md](./README.md) for the Chinese documentation with installation, configuration, and operational details.
