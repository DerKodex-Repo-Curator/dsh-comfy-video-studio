# dsh-comfy-video-studio

[中文](./README.md) | English

A full-screen ComfyUI MiniMax H3 video studio for DeepSeek Harness. It provides text-to-video, image-to-video, and one-to-three arbitrary-time keyframe workflows; validated workflow presets; persistent generation history and user-defined prompt templates; prompt optimization through the current Harness model; image upload, live progress, Range-enabled playback, and delivery to any absolute directory on the Harness host.

See [README.md](./README.md) for the Chinese documentation with installation, configuration, and operational details.
